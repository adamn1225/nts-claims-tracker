# Power Dialer Tutorial Script (Under 2 Minutes, No Real Calls)

## Goal
Teach non-technical users how to run a Power Dialer session quickly, log outcomes, and move to the next contact without placing live calls.

## Demo Safety Setup (No Real Calls)
- Turn on Manual Mode before starting the session.
- Use demo contacts only.
- Do not click the blue Call button during the tutorial.
- Add notes that include the word DEMO so records are easy to identify.

## GoTo Integration Setup
Before showing the dialer itself, mention that Power Dialer depends on a connected GoTo Connect account.

### What To Show First
1. Open Settings.
2. Go to the GoTo Connect section.
3. Connect the account if it is not already connected.
4. Choose a preferred device if needed.
5. Return to Power Dialer and continue the tutorial.

### Simple Presenter Line
"Before we use Power Dialer, we need to connect GoTo Connect in Settings so calls can be placed through your desk phone or softphone."

### Why This Matters
- It explains where the calling feature comes from.
- It makes the setup feel complete for new users.
- It helps people understand that Power Dialer is tied to their GoTo account.

## 5-Minute Training Version (Detailed)

### Part 1: What This Feature Does
Power Dialer helps you work call lists in order and log outcomes immediately so nothing gets missed.

### Part 2: Setup Screen Walkthrough
1. List Source:
Task Queue is best for day-to-day follow-up work.
Customer List is best when you want to run outbound calls from your full book.
2. Filters:
Use one or two filters only. Too many filters can hide contacts you still need to call.
3. Business Hours Filter:
Enable this if you want the system to help avoid calling outside local business hours.
4. Call Pacing:
Manual Mode means no automatic dialing and is the safest option for training.
If Manual Mode is off, auto-dial delay controls how long to wait before next call.
5. Customize Contact List:
Exclude contacts you do not want in this session.

### Part 3: Live Session Walkthrough
1. Read the task and customer snapshot before logging.
2. Open the queue panel any time to see who is next.
3. Log an outcome after each contact.
4. Add notes that another broker can understand in under 10 seconds.
5. Use Save and Next to keep momentum.

### Part 4: Callback Example
1. Select Call Back Later.
2. Pick callback date.
3. Add short context note.
4. Save.

### Part 5: Session Close
1. Click End Session.
2. Review summary metrics.
3. Confirm important follow-ups are scheduled.

## Audience-Friendly Talking Points

### Keep It Simple
- You do not need to change every setting.
- Start with Task Queue and Manual Mode.
- Log outcome and move to next.

### What To Say Repeatedly
- One contact at a time.
- Log every result.
- Save and Next keeps you moving.

### What To Avoid Saying
- Avoid technical terms like API, sync, webhook, event stream.
- Avoid long explanations of every button.
- Avoid discussing edge cases in intro videos.

## Common Mistakes To Cover In Training
1. Forgetting Manual Mode during demos.
2. Applying too many filters and thinking contacts are missing.
3. Skipping notes that teammates need later.
4. Ending a session without checking callback tasks.
5. Mixing demo notes with real customer notes.
