Technology Stack Overview

Core Framework & Language

Next.js 14
A modern React framework that handles both the user interface and server-side logic. It provides fast page loads, built-in routing, and automatic code optimization. Think of it as the foundation that everything else builds on top of.
TypeScript
JavaScript with type safety. Catches errors during development instead of in production, making the codebase more reliable and easier to maintain.

Database & Backend

Supabase
An open-source Firebase alternative that provides three key services in one:
  • PostgreSQL Database - Industry-standard relational database storing all customer data, tasks, and user information
  • Authentication - Handles user login/signup with email/password and Microsoft SSO integration
  • Realtime - Live updates across users (when one broker updates a customer, others see it instantly)
  • Row Level Security (RLS) - Database-level permissions ensuring brokers only see their assigned customers

User Interface

Tailwind CSS v4
Utility-first CSS framework for building custom designs quickly. Instead of writing custom CSS files, we use pre-built classes that make the interface consistent and responsive across all devices.
Lucide Icons
Clean, modern icon set used throughout the UI (phone icons, mail icons, calendar icons, etc.)
Custom Components
Built from scratch: KanbanBoard, CalendarView, CustomerMap, modals, tooltips - all designed specifically for freight broker workflows.

Data Handling

Papa Parse
CSV file parser for importing customer data from spreadsheets
XLSX Library
Handles Excel file imports (.xlsx, .xls formats)

Smart column mapping system auto-detects fields like "Business Name", "Phone", "Email" to streamline imports.

Deployment & Hosting

Netlify
Cloud platform optimized for Next.js. Provides automatic deployments, global CDN, serverless functions, and SSL certificates. Every git push triggers a new deployment.

Future Additions

React Native
Mobile app planned for iOS/Android. The codebase is being kept modular to share components between web and mobile versions, ensuring brokers can manage urgent follow-ups 24/7 from their phones.
SendGrid
Email service for task reminders and notifications (integration planned)
Calendar Export
iCal integration for syncing follow-ups with external calendars

Why This Stack?

  • Speed - Next.js + Netlify deliver fast page loads critical for brokers working between calls
  • Real-time Collaboration - Supabase Realtime keeps team members synced without manual refreshes
  • Mobile-First - Tailwind's responsive design + planned React Native app = full mobile functionality
  • Scalability - PostgreSQL + Supabase can handle growing customer databases and user bases
  • Developer Experience - TypeScript catches bugs early, Tailwind speeds up UI development, Next.js simplifies routing and API endpoints
  • Cost-Effective - Supabase and Netlify offer generous free tiers, with predictable pricing as the app grows
